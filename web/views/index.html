      The honesty test

      I hid the last week of sales, guessed it, then compared with what really sold. The numbers show how far off each guess was, in pieces per item. Lower is better.

      How it works

      1. Read the two files. Ordinary parsers read the sales report and the stock report. No AI reads them.
      2. Guess the next 7 days. TabPFN guesses each item's sales for each of the next 7 days, from that item's own past sales.
      3. Decide the order. Plain arithmetic compares the guess with the stock left, finds the day each item runs out, and works out how much to order.
      4. Word the note. Gemma only rewords each finished line. It never sees an item name or a number, and code checks every line it writes.

      Limits

      • The busy-week number is meant to cover about 8 weeks in 10. On the real shop it covered 66 percent.
      • Scanned, photographed or handwritten bills are not read.
      • Items sold on fewer than 3 days are set aside as too rare to predict.
      • This online demo checks at most 40 items per run and files up to 5 MB each. It keeps nothing on disk and forgets results after 30 minutes.
      • On this site, quantities and dates go to Prior Labs' TabPFN service, and sentences with blanks go to Gemma through Google. Item names go to neither.
      • The host sleeps when idle, so the first visit can take about a minute.
